# Репродьюсер: tests-layout

`sh .harness/reproducers/tests-layout/run.sh` проверяет временные Git-репозитории:
неверный корень, частичный staging, нарушение в неизменённой части index,
подмену типов, отсутствие снимка и отказ через настоящий hook → gate.
Каждому нарушению противопоставлен допустимый снимок; исходы наблюдаются по exit code.
Тест full-index не проходит при замене проверки на always-pass/diff-only.
Норма структуры утверждена пользователем; самотест показывает её исполнение,
а не выдаёт искусственную фикстуру за исторический инцидент.
