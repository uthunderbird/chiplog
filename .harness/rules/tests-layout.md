## Правило

Полный index tests должен соответствовать корневым категориям и типам записей
из tests/AGENTS.md. Смысл размещения проверяет ревью, гейт держит только путь/тип.

## Где живёт

Commit-гейт: tests_layout.py --index, подключён через run в gate.sh.
Рабочая диагностика: tests_layout.py --worktree. Парные снимки находятся в
tests/tooling/test_tests_layout.py; run.sh запускается test.sh и gate self-test.

## Дешёвый обход

Проверить только staged diff и пропустить неверный файл, уже лежащий в HEAD;
либо исправить worktree, оставив нарушение в index. Оба входа проверяются отдельно.

## Как удалить
