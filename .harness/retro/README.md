# Ретро

Каданс: раз в ~5 коммитов плюс внеочередной заход по инциденту. Гейт считает сам.

Две дисциплины:

1. Ретро обязана довести хотя бы один урок до правки харнесса — либо прямо сказать,
   почему в этот раз нет.
2. Ретро заканчивается коммитом. Запись коммитится всегда, включая честное «почему нет»,
   чтобы серия пустых отказов осталась видна в истории невооружённым глазом.

Заводить: `./.harness/scripts/new-retro.sh`

Разбор может вести агент: перечитать сигналы, довести каждую проблему до корневой
причины или хотя бы до класса, взвесить кандидатов. Роль человека сдвигается в конец
цепочки — обработчик исключений. Механизируется исполнение нормы; устанавливает её
по-прежнему человек.
