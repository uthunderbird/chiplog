Он касается любой новой черновой ретро после серии `skip`, а не только сегодняшнего имени файла. Отдельно merge-внесённая запись требует определения её порядка по first-parent истории. Статус теперь берёт outcomes из `HEAD`; для записи, впервые вошедшей через merge, позицию определяет first-parent ввод этого файла. Обычный gate mode по-прежнему отвергает пустой draft.
